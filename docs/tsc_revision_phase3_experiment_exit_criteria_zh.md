# 第三阶段实验收尾与后续阶段判据

本记录规定如何在第三阶段结束后判断是否仍需实验，不是论文正文或审稿回复。当前第三阶段的两种协议共 90 个正式单元正在运行；本文件不改变已冻结的策略、样本、参数、评分或计时规则，不提前认定正式结果。

用户已授权：第三阶段先形成完整成绩单与问题台账；仍影响回应审稿人的核心实验问题，继续进入下一阶段；证据足够后停止追加实验，再修改正文。所有阶段都保留失败、覆盖损失和成本。

最新收口指令进一步限定：第三阶段是最后一次返修风险修补与独立验证，不做 ContractKV 2.0。保留原四项贡献，不增加证书体系或性能优化矩阵。正在运行的冻结验证完成后，仅作用域内稳定复现的实质退化、错误准入、发布/身份不变量或使主要结论失真的证据错误值得继续修复；其余负性能与已明确边界据实报告，尽快转入正文和 Response Letter。

随后用户明确了本次交付顺序：达到上述实验条件后，先交付逐条审稿意见的实验证据回应，以及补强实验总报告两份文档；正文文本修改及其最终回复位置后续再处理。本次不把正文改写算作已经完成，也不以继续写正文推迟这两份文档的交付。

## 完成第三阶段的必要条件

1. 冻结的闭环 36 单元、固定到达 54 单元均完成，或明确记录不可恢复的外部阻碍；不以部分成功单元替代全矩阵。
2. 实际 prompt/output IDs、首次分歧、冻结任务分数、资格与回退路由均完成审计。统计同时给出编译路由和全部路由；重复、tenant 和协议不能冒充独立来源。
3. 冷会话与十 tenant 分开报告完整 wall、收益门禁实际筛除、资格成本、覆盖率、均值及 p99。固定到达协议报告相同计划到达、排队、验证等待及 drain；不把含空闲的固定负载完成时间当作容量。
4. 全局、任务族、来源模板、tenant、请求层结果可追溯。CI 保留来源/重复相关性；宽区间跨零不解释为等价或非劣。
5. 远端归档逐成员验证、本地恢复与独立重算完成，公开提交的远端 SHA 核对完成，自有 GPU 服务退出。哈希一致只证明证据身份，不证明科学目标成功。
6. 在开始下一阶段实验之前，先给出第三阶段完整报告，列出正负结果、原因证据、未证实解释及下一项可证伪检查。
7. 核对原部署模板模式与 query-bound 保守模式的实现对应：模板身份、行为作用域、见证来源、发布动作、跨 tenant 复用与完整认证次数分别计数。不能把保守模式的结果直接替换成原部署模式，也不能仅用两种索引宣称实现了两个独立证书。

## 哪些问题触发下一阶段实验

| 观察到的问题 | 必须先查的证据 | 后续处理判据 |
|---|---|---|
| 新编译路由的输出或任务分数下降 | 对应 raw/reference/candidate 的实际完整 IDs、作用域变化、margin、缓存读取和重复条件 | 实现错误、错误放行或与拟保留保证直接矛盾，必须修复并在新冻结来源验证；若是有限 witness 外的已知适用边界，必须诊断并收紧可支持主张，不能保留普遍安全说法 |
| 收益门禁没有真正筛除，或预测与实际成本严重失配 | 事前/事后拒绝原因、信息成本、GPU 认证与失败成本、可用对照标签和未知标签 | 以现有独立验证和 CPU 账本检查回应。被拒绝的 scope 不能凭预测称为全部无效；筛除有效机会和覆盖代价同时报告。不再为提高通过率或收益数字增加复杂预测器；只有成本账本/实现错误影响主要结论才修复 |
| p99 高于 raw | 同到达/同调度/同成本的请求账本、raw 慢请求、资格等待、来源与重复不确定性 | 计时或调度不公平必须修正；真实负结果保留，不要求三模型普遍改善，不再因此引入异步准备或新调度算法 |
| 冷会话收益接近零或转负 | 全成本、实际命中、输出长度、覆盖、重复范围、预测复用量 | 区分实现/协议错误与适用条件；复用不足的真实限制据实报告，不再为了目标倍率开展新优化，不能通过删来源制造正收益 |
| 审计、身份或成本账本不完整 | 冻结源码、运行时清单、逐请求原始记录、归档与独立重算 | 先修证据链；冻结文件不覆盖，新增审计版本并保留原输出。缺失历史字段明确标不可得，不能事后补造 |
| 模板级摊销与 query-bound 方法不一致 | 原部署 attestation 的参考来源、实际客户端查表键、稳定前缀对象与行为 scope 数、逐 scope GPU 尝试及 tenant 复用 | 先做实现与账本审计。完整行为认证随 U 增长就报告 O(U)，固定 U 下的跨 tenant 摊销仍单列；若拟保留的新保证需要尚不存在的独立证书/在线绑定，必须实现并另立验证，不能只改术语 |

下一阶段若依据本轮正式结果修改方法或参数，本轮即成为已观察数据；新验证必须再排除已观察来源，冻结新版本后才运行。仅复算、诊断或对旧失败重放不能称为新的未见验证。

## 何时完成本轮并交付文档

每条审稿实验要求都应落到：已核验实证、仍需完成的核心实验，或审稿人允许且有证据支持的明确限制。没有未处理的核心实验缺口，且拟保留的论断不超出证据时，停止追加优化，交付逐条实验回应和总实验报告。正文、文献和排版意见在回应文档中逐条登记为后续处理，不虚构正文修改或页码。是否“全是好结果”不是收尾条件，实验完成也不等于修回稿已经可以提交。

依据为第一、第二阶段总报告、审稿意见证据表及第三阶段冻结协议；第三阶段最终数字待全矩阵和独立复核后填写。
