# Phase 4 Quality-Risk Ledger v0

## Status

Quality-Risk Ledger v0 is complete as a proxy schema artifact.

This ledger is not a model-scored benchmark result. It is a deterministic risk-prior table used to decide which segment/action combinations should be measured first in later ContractKV experiments.

## Inputs

- `results/datasets/sample_prompts.jsonl`
- Datasets: RULER, LongBench, RepoBench
- Max samples per dataset: 20

## Actions

Each segment is expanded over six lifecycle actions:

- `fp16_baseline`
- `segment_eviction`
- `context_truncation`
- `shifted_position_proxy`
- `boundary_corruption`
- `boundary_repair_proxy`

## Output

- `results/risk_ledger/quality_risk_ledger_v0.csv`
- `results/risk_ledger/quality_risk_summary_v0.csv`

The ledger contains 1080 rows:

| Dataset | Rows |
| --- | ---: |
| RULER | 360 |
| LongBench | 360 |
| RepoBench | 360 |

Risk distribution:

| Risk class | Rows |
| --- | ---: |
| low | 429 |
| medium | 480 |
| high | 171 |

## Interpretation Boundary

`quality_drop` is generated by a fixed proxy heuristic over segment type, segment token share, and lifecycle action. It should not be used as an accuracy number.

The useful conclusion is structural: the ledger now gives ContractKV a stable, auditable table for selecting high-risk segment/action pairs before expensive model-scored experiments.

The Phase 5 controller consumes `quality_risk_summary_v0.csv` as the initial `Risk(segment, action)` table for trace-level policy evaluation.
