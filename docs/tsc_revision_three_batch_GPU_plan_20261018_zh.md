# ContractKV：三批 GPU 补强目标与验收计划

## 总目标

按用户本次要求，优先完成能够直接增强机制贡献和实验说服力的 GPU 实验。保留 CALC、Scoped Certification、PSTP、Service-Template Certificate 的原有主线；不以新算法取代被审稿的方法，不根据新输出调阈值、换来源或挑选有利重复。实验和证据矩阵完成前，不重写正文和 Response Letter。

研究目标已登记为本聊天的 active goal。用户随后允许直接推进当前 GPU 实验；正式计时仍要求无其他 GPU 任务，不终止、不混跑其他人的进程。后续新增任务另行冻结，不能掺入本轮结果。

## 第一批：原 Table III 的同协议完整成本

- 四配置：Qwen3-8B、Qwen3-14B TP2、Mistral-7B、Llama-3.1-8B。
- 原六份冻结 session/qualification 文件、历史 renderer 和资格策略；Raw APC/Contract 两路，各三次 fresh-process 配对，共 24 cells、4,725 个未来配对。
- 保留原 slack 在策略/作用域构造中的原值；零 slack 只用于明确的完整成本计账，另外直接测完整 wall。
- 记录所有成功、拒绝、异常、每次下降尝试、原始见证、准备、RPC、完整 controller、业务时延和最终 drain。所有路由、L0、输出变化均保留。
- 并列报告历史 residual-RPC 结果和新完整计时；新测时长不冒充找回的旧时间戳。不同分母、组件计账和直接服务时钟分开。
- 验收：预定配对齐全、逐请求键对应、每个 canary/尝试具有实际计时、失败不再被覆盖成零、实际 backend 完成后停止计时。任何负收益都保留。

原有 `protocol_v1.json` / `freeze_v1.json` 不变。此次预检已完成四模型全分片 SHA；运行时复制的符号链接清单问题记录在单独 repair 中，尚无 GPU 业务推理。修复仅覆盖文件清单，不修改认证策略。

## 第二批：跨模型、多语义的行为准入必要性

主体为三个 7B/8B 模型，已有 Qwen14B 探针作独立规模对照。覆盖五类：指令顺序/优先级、RAG 证据位置、tool observation 与 query、代码上下文、EOS/终止。

在任何本批 GPU 输出出现前冻结：完整案例内容和 hash、合法依赖图、实际 CALC 候选、候选/安全对照、评分、生成预算、现有认证阈值、重复与来源单位。数量和执行清单将在 CPU 构造审计后单独冻结，不能看 GPU 结果再扩充有利案例。

每个候选必须有实际 Raw、未经认证的同候选 Layout-only、认证记录及认证后的真实业务路由输出。加入同输入 Raw 重复控制，记录实际 Prompt/输出 IDs、首次分歧、任务分数、EOS、发布长度/块数与费用。

验收指标：正常候选放行、观察到的行为变化/实质退化的拒绝、错误准入、拒绝候选实际共享发布、路由后的质量和认证成本。将预设风险类型与实际观察的有害结果分开：没有发生变化的风险案例不能事后叫坏布局；得分提高也不等于行为认证成功；Raw 本身不稳定的情况单列且不删除。

区分原有 frozen-safe D1 与本批未经资格检查的 candidate-layout 对照。不得把一个未被原 D1 部署允许的坏候选伪装成其正常部署表现；本批测试的是对同一候选执行或跳过行为准入的后果。使用真实已实现路径，不虚构 Certification-only 独立系统。

## 第三批：有限的合成 Manifest 信任边界闭环

仅使用合成、可公开的敏感样式标记，不使用真实个人信息。冻结三类情况：

1. 显式 PRIVATE/MUTABLE 内容申请共享：记录实际在哪一层拒绝，并检查引擎是否出现候选发布。
2. 可信运营者将合成私有标记误声明为 STABLE/shared：先记录注册是否接受，再记录行为认证和实际 PSTP 发布是否成功；不能从 CPU 接受直接推断 GPU 泄露。
3. 两租户的私有槽位值相同/不同及授权域对照：核对实际 token 前缀、共享边界、命中和身份，不把 Hash 匹配当作完整保密性防御。

注册 helper、可信客户端 HMAC 选路、引擎 PSTP 各自记账。若某个检查只存在于 CPU helper 或受控客户端适配器，就准确写明；不宣称已实现公共认证网关。正确标注的同域匹配正对照必须能证明实际可命中，避免因缓存没开启而得到假阴性。

结果不要求“全部拦截”。可信运营者语义误声明可能被接受并在其他门禁通过后实际发布，这正是需要真实检验的信任边界。不得删掉不利结果，也不将该实验扩展成侧信道防御项目。
