# ContractKV：保真输入独立验证结果

更新：2026-10-17，Asia/Hong_Kong。**18/18 完成；主分析、实际 IDs 与原始归档核对完成。** 本文件记录原版保真 R4 的独立结果，成本适配另列，正文尚未修改。

## 实验回答的问题

在只恢复任务输入结构、保留原 R4 的 CALC、严格行为作用域、margin、Python 准入和 PSTP 的条件下，新 HotpotQA/RepoBench 来源是否仍能形成合法复用与全成本收益？

六个来源按预注册 hash 顺序与容量选择，排除既往 567 个来源；三个 HotpotQA、三个 RepoBench。四来源 Qwen 开发结果没有混入本表。三模型、三次新进程、raw/策略配对，共 18 单元、10,800 次业务生成；9,720 次未来生成形成 4,860 个 raw/策略未来配对。

共同 16K 窗口；完整 query、CODE_PREFIX 与原有空白保留，两个 QA 来源按与答案无关的冻结规则裁剪可选上下文，四个来源完整保留。三个 HotpotQA 来源的参考字面串均在最终上下文内；这只证明字面可达性，不证明模型能正确作答。RepoBench 仍使用冻结的 SequenceMatcher 类评分与原输出准入，不声称是作者官方任务协议的完整复现。

原两请求闭环 wave、到达/准备计时规则保持不变。完整服务 wall 包含所有实际业务、规划、认证及失败等待；服务端启动和一致的前测分开记录。这是闭环服务实验，不是开放到达容量或 SLO 保证。

## 全成本、覆盖与尾部

| 模型 | 编译未来配对 | 完整 wall 吞吐/raw | 三次配对倍率范围 | 未来 readiness p99，ms，raw → 策略 |
| --- | ---: | ---: | ---: | ---: |
| Qwen3-8B | 684/1620 (42.22%) | 1.6190× | 1.6148–1.6226× | 8561.8 → 9146.6 |
| Mistral-7B-Instruct-v0.3 | 342/1620 (21.11%) | 1.1091× | 1.1074–1.1102× | 9418.2 → 9511.3 |
| Llama-3.1-8B-Instruct | 270/1620 (16.67%) | 1.0703× | 1.0681–1.0715× | 7851.3 → 7905.7 |

该倍率范围是三个进程重复的 min/max，不是来源簇置信区间。只有六个独立来源，租户与重复相关，不能按数千个请求视为独立来源。

Qwen 的 HotpotQA/RepoBench 编译未来数分别为 516/810、168/810；Mistral 为 342/810、0/810；Llama 为 270/810、0/810。后两者 RepoBench 继续继承开发时冻结的家族 L0，不能把零覆盖全部归因于新保真输入或新来源的认证失败。

三模型都有非 RULER HotpotQA 覆盖，解决了旧 R4 本批 Mistral/Llama 仅观察到 RULER 编译收益的问题，但不证明所有任务/来源都能复用。这些新结果与旧 R4 来源不同，不能把 1.106×→1.619× 等跨批数字差全归因于输入修复；输入因素的直接控制证据仍是此前同四来源开发四格。

**p99 仍是权衡。** 三个 pooled 点估计均上升。Qwen、Mistral、Llama 的 p99 降低百分比来源簇/重复 95% 区间分别为 [-56.247,26.802]、[-60.576,-0.137]、[-16.784,0.151]。尤其 Mistral 本表区间完全位于负侧，应保留尾部变差的证据。平均 readiness 改善和全成本正收益不能替代普遍 p99 改善。

## 自由生成与绝对任务质量

1,296 个编译未来配对无输出 ID 分歧、无任何冻结分数下降。计入初始业务，共 1,440 个编译配对也无输出/分数变化。Qwen 全部 1,800 个业务配对均保持 IDs/分数一致。

全路由仍保留四次 >0.03 下降：Llama 未来请求三次，Mistral 初始业务一次。未来全路由还存在 Llama 五次 >0.03 上升；初始与未来合计为 Llama 五升三降、Mistral 两升一降，均发生于 L0。上升与下降不抵消，行为变化也不因得分提高而成为等价认证成功。

四个选定 L0 异常位置包含三次未来掉分及初始长输出变化等。所有对应 L0 输出签名都在预定 raw 重复中出现。Llama 共同 L0 的 1,350 个未来配对有五升三降；同位置相关 raw 重复为七升七降。该结果支持原生路径存在变化，不能证明策略与所有异常无因果关联；三个 pairwise raw 比较复用了控制，不能作独立事件频率检验。

**相对保持不保证绝对正确。** Llama 在 doc109/doc19 的 raw F1 为零，对应来源仍各有 90 个保持同样错误行为的编译未来配对。Mistral doc19 也有 84 个零分参考的编译未来配对。Qwen 的获准子集具有正的冻结任务分数，但评分仍非语义正确性证明。完整逐来源 raw/策略质量与字面可达性均保存，不能只展示获准后的零退化。

资格有效不代表当前 KV 全部驻留。全部已编译业务的完整/部分/零 native 命中分别是 Qwen 720/12/0，Mistral 324/0/42，Llama 207/0/135。逐请求稳定前缀 hash 与行为资格绑定通过，零命中本身不能被解释为认证错误或不安全发布。

日志记录的 pool 分别为 31,040、56,800、38,704 tokens；没有匹配到 preemption 警告。现有计数没有逐块驱逐轨迹，不能据此确定零命中来自驱逐或某种执行路径。保留这些损失，不以“所有获准请求都完整命中”概括结果，也不为此扩展新缓存调度算法。

## 可复核性与后续决策

预注册 `aa7b00ddba8e223e6b1e6d533cf7021be24bb7ec` 在首个 forward 前公开；248 文件冻结不改。原始包 443 成员、9 分卷、272,635,421 bytes，SHA256 `fcd60a06a6b3832dcbeb5c052ed733f700cd879a15fe72800e2d488bfee09d6b`；远端和本地逐成员核对通过。本地独立重算 15 份主分析、6 份补充分析、4 份 raw/L0/质量分析和 2 份 Table I 文件，与独立远端结果逐项完全一致，无数值差异。

10,800 个实际业务 Prompt IDs 与 108 个候选计划逐请求重建；完整 IDs、输出、实际时钟与物理指标均在原包。新 Table I 重建覆盖 5,400 个 raw 业务输入与 18 个模型/来源代表映射，仍不冒充恢复原稿缺失的精确百分比来源链。

**决策：** 本组没有出现需要扩大或重新设计行为认证的新编译反例。保留原四贡献，继续只运行已预注册的单一成本候选 DEV 三路，处理长输入同步认证的可避免等待；通过固定开发条件才增加最多九个另选来源的 Qwen 对照。主 18 的方法、来源、指标与失败不改；无统一 p99、生产唯一 query 或绝对任务正确保证。
