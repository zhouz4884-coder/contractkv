# Story V3 修改说明复核与作者简介版面实测

日期：2026-10-17。对象：`Paper/revision_story_v3_20261017`，主文 12 页、补充材料 6 页；基线提交 `519367227130fac8a9e1ddefd95962e8e477d5c1`。

本轮任务是阅读用户新提供的审稿式评估，并核查已发表 TSC 论文的作者简介与当前稿件的空间预算。本文是工作记录，不是 Response Letter。未运行新 GPU 实验。

## 1. 结论与决定

**两位作者的简介合计预留约四分之一页是合理的，通常可以更少；不应仅为简介预先迁移半页正文。**这里的四分之一页指双栏正文页的面积，不是四分之一栏。

采用每人一段、约 50–70 个英文词的目标即可；只保留真实学历/当前身份和少量研究方向，不罗列不必要的获奖、论文数量和履历。这个词数是本稿的编辑目标，不是 TSC 强制规定。照片占用也要算进预算。

当前末页的剩余空间不足以直接追加两段带照片简介，仍需少量文字精简或末页重排。正式作者资料尚未提供完整，不能将内部排版试文当作已完成的简介。

## 3. 用本稿 IEEEtran 模板实测

方法：复用本稿 `IEEEtran` journal 模板和已检查的 `scripts/compile.py`，不缩字号、不改页边距。两段中性排版试文分别为 50 和 69 个空格分词，不涉及任何真实作者的学历、职称或研究经历。带照片条件使用模板默认的 1.0 × 1.25 英寸照片占位。

为测量自然高度，将两段置于同栏的自然高度容器内，避免模板中可伸长的竖向胶把空白撑满。保留模板默认的简介间隔；计算预算时另计第一段前约 36 pt 间隔。这里是版面测量，不是在正式稿中用负间距挤压简介。

| 测量 | 结果 |
|---|---:|
| 原主文页数 | 12 |
| 带照片两段简介的可见包络高度 | 218.25 pt，单栏宽 |
| 加第一段前间隔的规划预算 | 约 254.25 pt，单栏宽 |
| 折算双栏正文页面积 | 约 18.4% 页 |
| 不带照片条件的同口径预算 | 约 178.54 pt，约 12.9% 页 |
| 当前第 12 页右栏剩余高度 | 约 125.53 pt |
| 不精简正文，直接按默认环境追加带照片试文 | 编译到 13 页 |

结论：**预留 20%–25% 页比较稳妥。**当前末页不是完全放不下，而是还缺约 129 pt 的单栏空间，约等于十一行正常正文的高度；分页、参考文献流动与简介前间隔会影响最后结果。可以优先精简重复的协议提醒和收尾复述，再做完整编译。不需要为了简介删除性能主图或关键消融。

这不等于整篇修订只需节省十一行：新增协议比较表和展开信任模型还会消耗空间，应单独计入；不能把它们的空间需求全部算到作者简介上。

复现命令：

```powershell
python -B scripts/verify_tsc_biography_layout.py
```

产物：`submission/biography_layout_audit_20261017/layout_audit.json` 及两份明确标为内部测试的 PDF/TeX/PNG。直接追加后的 13 页测试稿仅在 `.artifacts/bio_layout_20261017/reproducible_append_test`，不替代主文。
