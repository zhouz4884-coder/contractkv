# 第二阶段第二批独立验证：完整结果与未达目标

36/36 cells、27000 次实际业务生成、24300 个未来请求已完成，远端全量审计通过。两个策略使用配对输入、同一 GPU、相同数值运行环境与模型身份，三个独立服务重复；112 个源码/输入文件在首次 forward 前冻结并公开。R3 是第二阶段内部的第二次准入修正，不是已经启动第三阶段。

本轮达到十租户吞吐与平均 readiness 改善，三模型的十租户编译输出均没有任务分数下降。但是，**新样本编译退化为零、冷会话三模型稳定获益、三模型尾延迟共同改善，都没有全部达到。**

## 输入与策略

从既有来源池按 seed 10672130 冻结另外 50 个来源，每族 10 个，排除全部 412 个既往来源；十租户条件在生成前取每族前两个来源。第一批独立验证的 50 个来源已转为观察过的开发数据，本轮没有复用它们作为未见验证。

策略保留事前收益门禁、每个 scope 最多一次在线认证、失败立即 L0、参考 logprob 采集去重以及实际完整 prompt token IDs/SHA256。raw 下限为 0.0625，candidate/自然 EOS 下限为 0.125。RepoBench 另加单条完整 Python 语句准入，不执行代码、不改写输出、不使用 gold 分数。固定档位与成本模型沿用开发选择。门禁和单次尝试的 CPU/RPC 成本均计入实际完整 wall，没有事后扣除失败成本。

实际 1188 个进入计划的 scope 全部通过了事前收益预测，因此不能把本轮节约归因于“收益门禁实际拦截了请求”。逐 token raw margin 提前拦截 142 个，Python 语法准入拦截 27 个；其余 1019 次真实 GPU 认证有 714 次获准、305 次拒绝。每个 scope 都最多一次认证，没有连续失败降档。收益预测在这批输入上的区分能力和尾延迟约束仍不足，是下一阶段成本模型的重点。

共 12150 个 raw 配对未来请求，4965 次实际编译，保留 3 次编译下降及 12 次真实 raw 回退下降。3 次编译下降来自同一个模型/来源/query 单元，不能当成 3 个独立失败来源。十租户的 3612 次编译未来输出没有任何分数下降或相对配对 raw 的输出 ID 分歧。冷会话其余编译输出也没有分数下降；所有 ANY、0.01/0.03/0.05 阈值、首次分歧与 witness 长度数据均保留在 CSV。

新失败为 Qwen 的 NarrativeQA doc99、t7，三个重复的 F1 都是 0.121212→0.071429。compiled 完全保持 t1 的获准参考：结尾是 “the answer is not available in the given context”。未来 raw 改用较长的 “there is no information to answer this question based on the given context”，首次 token 分歧位置为 24（从 0 计数）。两个表述都表示信息不足，这仅解释词面指标变化，不取消冻结 F1 的下降。

参考与对应原始路径在实际 prompt IDs 和输出 IDs 上均相同；配对策略在同一 GPU 上运行，三个重复的 GPU 分别为 0/1/0。参考 raw 最小 margin 是 0.09375/0.125/0.125，candidate 最小 margin 均为 0.40625，明显高于当前 candidate 门槛。因此，现有证据指向“获准参考与未来动态输入响应不同”的范围问题；它不是缺失 prompt 日志，也不是这次门槛能拦截的 candidate 近并列。没有为消除这个新测试失败而修改正式准入、评分或事后路由标签。

12 次 L0 下降照常计入全路由结果。审计确认对应 raw 回退与基线实际 prompt IDs 相同；其服务执行批形状及同输入 raw 波动仍需另行诊断，不能仅凭路径标签把所有差异归因于编译或证明与编译完全无关。

Qwen 十租户 p99 点估计下降约 35.85%，但区间跨 0；Mistral 点估计接近 raw，Llama 略高于 raw。没有三模型共同显著改善尾延迟的证据。尾部描述审计显示，Mistral/Llama 每个重复最慢的 9 个未来请求全部是继承 L0 的 RepoBench，额外 RPC 前等待均值约 23–34 ms；Qwen 最慢 9 个请求也都走 L0，但仍有约 889–900 ms 的同步前置等待。不同模型的尾部原因不能统一归结为认证次数。

置信区间使用配对服务重复和来源簇：冷会话以共享 readiness 屏障的两个来源为一个簇，十租户以包含全部租户的来源模板为簇。均值抽样 3000 次，p99 抽样 2000 次，后者 seed 为 10672129。完整 wall 的不确定性列三个重复范围，不冒充来源级 wall 区间。模型常驻启动不计入业务 wall；实际规划、业务、认证、失败与同步等待计入，warm 成本也保留。十租户有 100 个会话、并发为 2，并非 100 路同时解码。

本轮仅有 raw 与新策略，没有在本轮来源上运行 legacy。因此不能把本轮数值直接减去第一批 legacy，宣称同输入的新增因果改善；第一批对 legacy 的配对比较保留在单独报告。
